## 🔧 Day 1 Issues - Troubleshooting

### If Payment Not Working
1. [ ] Check Razorpay keys are LIVE (not TEST)
2. [ ] Verify webhook is configured
3. [ ] Check amount is in paise (amount * 100)
4. [ ] Verify signature verification logic
5. [ ] Check database connection
6. [ ] Review error logs in Sentry
7. [ ] Reach out to Razorpay support

### If Downloads Not Working
1. [ ] Check AWS S3 credentials
2. [ ] Verify files exist in S3
3. [ ] Check file permissions
4. [ ] Verify download link generation
5. [ ] Test with direct S3 URL
6. [ ] Check browser console for errors
7. [ ] Review server logs

### If Email Not Working
1. [ ] Check SendGrid API key
2. [ ] Verify email address is valid
3. [ ] Check spam folder
4. [ ] Review SendGrid activity log
5. [ ] Test with test email
6. [ ] Check email template
7. [ ] Verify domain authentication

### If Server Down
1. [ ] Check server status on hosting platform
2. [ ] Review error logs
3. [ ] Check for DDoS attacks
4. [ ] Verify SSL certificate
5. [ ] Check database connection
6. [ ] Review resource usage
7. [ ] Activate backup/restore procedure
